# Ejercicios de Programación Orientada a Objetos (POO) - Python

Repositorio creado para el desarrollo y práctica de la guía de Programación Orientada a Objetos en Python, aplicando conceptos fundamentales como clases, atributos, métodos, constructores, objetos y separación de responsabilidades.

## 📂 Estructura del Repositorio

El proyecto se encuentra organizado en carpetas independientes para cada uno de los ejercicios:

* 📁 **`Ejercicio1`**
  * **Descripción:** Cálculo de las edades de Juan, Alberto, Ana y la mamá mediante proporciones y operaciones matemáticas aplicadas con POO.
  * **Archivos:** `main.py`, `operation.py`

* 📁 **`Ejercicio2`**
  * **Descripción:** Implementación y seguimiento de una serie de instrucciones matemáticas mediante variables, operaciones y una clase encargada de realizar el cálculo.
  * **Archivos:** `main.py`, `operation.py`

* 📁 **`Ejercicio3`**
  * **Descripción:** Cálculo del salario bruto, la retención en la fuente y el salario neto de un empleado a partir de las horas trabajadas, el valor de la hora y el porcentaje de retención.
  * **Archivos:** `main.py`, `operation.py`

* 📁 **`Ejercicio4`**
  * **Descripción:** Cálculo del cuadrado y el cubo de un número utilizando métodos de la clase `Numero`.
  * **Archivos:** `main.py`, `operation.py`

* 📁 **`Ejercicio5`**
  * **Descripción:** Cálculo del área y la longitud de la circunferencia de un círculo a partir de su radio, utilizando operaciones matemáticas y la constante π.
  * **Archivos:** `main.py`, `operation.py`

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python

---

## 📚 Conceptos de POO Aplicados

* **Clases:** Cada ejercicio cuenta con una clase encargada de representar y procesar la información correspondiente.
* **Atributos:** Se utilizan para almacenar los datos necesarios para realizar las operaciones.
* **Métodos:** Encapsulan las operaciones y cálculos de cada ejercicio.
* **Constructores:** Se utiliza `__init__()` para inicializar los atributos de los objetos.
* **Objetos:** Se crean instancias de las clases desde `main.py`.
* **Modularidad:** Cada ejercicio está separado en `main.py` y `operation.py`, facilitando la organización y reutilización del código.
